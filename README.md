# ⚔️ 旷野传说 · 回合制冒险 RPG

**🎮 在线游玩：https://yjj0339.github.io/kuangye-chuanqi/**

纯前端回合制 RPG 小游戏，无需安装、打开即玩，进度自动保存在浏览器本地。

## 玩法特色

- **🗺️ 六张野外地图**：微风草原 → 翠影森林 → 流沙荒漠 → 冰霜雪原 → 熔岩火山 → 苍穹神殿，探索度满解锁关卡大Boss，击败后开启下一张地图
- **👹 六档野怪**：普通 / 精英 / BOSS / 暗金小Boss / 关卡大Boss / 终极Boss（苍穹龙王）
- **💎 随机装备属性**：6 部位 × 6 品质（白/绿/蓝/紫/橙/暗金），15 种随机词条（攻击%、暴击、吸血、伤害减免……），暗金装备带专属强力词条
- **📈 角色升级**：升级获得自由属性点（力量/体力/敏捷/精神）+ 技能点
- **✨ 技能体系**：10 个主动技能（连斩/烈焰冲击/雷霆万钧/末日审判……）+ 6 个被动技能，均可升 5 级
- **🔨 装备锻造**：强化 +15（失败会掉级）、洗练重随词条、材料打造、暗金打造、分解回收
- **🎁 探索遭遇**：普通怪群、精英小队、稀有 BOSS、暗金小Boss（60 次探索保底）、宝箱
- **💾 自动存档**：每次行动后自动保存，刷新/关闭不丢进度

## 本地运行

直接双击 `index.html` 即可游玩；或启动局域网服务器（手机也能玩）：

```bash
node tools/server.js
```

## 平衡性验证

`node test/balance.js` 会用真实游戏数据模拟各等级、各装备档次与六档怪物的战斗胜率（每场 120 次）与升级节奏。

## 技术

原生 HTML/CSS/JavaScript，无框架无依赖，明亮浅色主题。
